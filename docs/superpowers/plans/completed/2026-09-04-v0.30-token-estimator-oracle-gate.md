# FocalSpan v0.30 TokenEstimator oracle gate 計画

**Goal:** Estimator非依存bytes計測を維持し、承認済み実tokenizer oracleが存在する場合だけ
固定1.12係数の校正候補へ進む。

## Purpose / Big Picture

Estimator自身で計測したwireだけでは係数変更の実削減を証明できない。v0.21でUTF-8 bytes
防止線は追加済みなので、oracle不在時は係数を変更しない。

## Baseline and Gates

- accepted baseline: wire 11,693、bytes 32,494、useful 5、効率0.4276。
- 実token oracleへの過小見積もり0、packet bytes非増加またはuseful増加。
- oracleがなければ製品変更・候補ベンチを行わない。

## Global Constraints

- network、external LLM、model-specific tokenizerの無断導入を行わない。
- 係数だけを下げて改善と報告しない。
- `AGENTS.md`、`.focalspan.json`、`TASKS.md`を変更・stageしない。

## Validation and Acceptance

oracleがある場合のみ校正する。不在時はEstimatorと全baselineをbyte-identicalに保つ。

## Idempotence and Recovery

read-only調査のみ。製品候補を作らない。

## Interfaces and Dependencies

公開interface変更なし。調査対象は`internal/budget`と既存依存のみ。

## Decision Log
